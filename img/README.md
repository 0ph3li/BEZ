# BEZ · photos

Every photo is a slot: drop a file in the right folder with the right name and it shows up. The extension doesn't matter (`.jpg`, `.png`, `.webp`, `.jpeg`, `.avif` are tried in that order). An empty slot shows a soft frame in the photo's tone, labelled with the filename. Run `bez.missing()` in the console to list the empty ones.

Cutouts (`.png` with transparency) are trimmed to their content. Each folder keeps the untouched originals in `_orig/`.
